# Dependencies

- Fastify: HTTP routing, bounded request bodies and injection tests.
- Zod: shared input/output and startup configuration validation.
- TypeScript / tsx / Node types: strict compilation and local TS runtime/tests.
- React / React DOM / Vite / React Vite plugin / React types: client rendering and production bundling.
- Tailwind CSS 3 / PostCSS / Autoprefixer: explicit Tailwind configuration matching the supplied tokens.
- Fontsource Manrope / Hanken Grotesk: bundled, self-hosted font files without external browser requests.
